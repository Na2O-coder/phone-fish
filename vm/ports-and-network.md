# 端口与网络

| 端口 | 用途 | 是否暴露 |
|---|---|---|
| 22 → 2222 | VM SSH（手机端口转发） | 仅手机本机 |
| 5099 | SnowLuma WebUI | 仅手机本机/VM |
| 3000 | OneBot HTTP | 仅 VM 本机 |
| 3001 | OneBot WebSocket | 仅 VM 本机；bridge 连接 |
| 6081 | noVNC | 仅手机本机/VM |
| 32146 | bridge 控制面 | 只监听 127.0.0.1 |

原则：

- 不要做公网端口映射；
- 不要把 3001/5099/32146 暴露到 0.0.0.0；
- bridge 的 OneBot host 用 127.0.0.1；
- DroidVM 的端口转发只给手机本机访问，不要分享给不可信设备。
