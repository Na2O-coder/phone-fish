# 视频/截图隐私检查表

## 必须打码

- [ ] QQ 号、群号、群名、昵称、头像
- [ ] QQ 登录二维码
- [ ] DeepSeek/ASR API key
- [ ] OneBot token、bridge control token
- [ ] VM IP、SSH 端口/用户名/密码
- [ ] noVNC/VNC 密码
- [ ] 手机通知、状态栏、最近任务
- [ ] 浏览器标签/书签/密码管理器
- [ ] 终端历史里的路径、用户名、token
- [ ] 私人聊天/家庭/关系内容

## 录制环境

- [ ] 使用独立演示 QQ 小号/演示群
- [ ] 不在线上 bot 的群录屏
- [ ] 手机桌面干净，隐藏私人 App/照片
- [ ] 关闭通知/勿扰
- [ ] 关闭自动同步/剪贴板同步
- [ ] 浏览器无痕/关闭密码保存

## 后期

- [ ] 逐帧检查二维码/通知/终端
- [ ] 马赛克不是半透明，不能反推
- [ ] 音频里不出现真实 QQ/群/姓名
- [ ] 简介/置顶评论不含真实账号
- [ ] 文件元数据（录屏坐标/设备名）已清理
- [ ] 上传前用另一台设备看一遍

## 如果泄露

1. 立即下架/设为仅自己可见；
2. 轮换所有相关 key/token/密码；
3. 检查账号是否被登录/操作；
4. 保留日志，评估是否需要进一步处理。
