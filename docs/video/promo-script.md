# B 站宣传片大纲（6–8 分钟）

## 定位

这不是“手把手安装教程”，而是：

- 介绍「手机养鱼」是什么、能做什么；
- 把门槛和风险讲清楚；
- 让观众自己判断要不要入坑；
- 完整步骤放到 GitHub 文档，不在视频里逐条敲命令。

目标时长：6–8 分钟。  
画幅：16:9，1080p。  
素材：手机录屏 + 少量 VM/SnowLuma 画面 + 架构图 + 文字卡。  
剪辑：剪映手机版即可；音频/图片由作者后期配。

## 一句话结构

手机能跑 → 但门槛不低 → 适合谁 → GitHub 有什么 → 不适合就省下时间。

## 分段大纲

### 00:00–00:45 冷开场：这不是电脑

画面：
- 手机放在桌上，QQ 聊天自动回复（演示号，全部打码）；
- 对方发文字/表情，AI 两秒后接一句；
- 切到手机桌面/VM 运行状态，证明不是电脑、不是云服务器。

口播：
“这条回复不是我在电脑上发的，也不是云服务器。就是这台安卓手机，自己跑着一个 QQ 小号。”
“但先说结论：这不是一键包，门槛不低。这个视频只告诉你它是什么、值不值得折腾；完整教程在 GitHub。”

字幕：
0 电脑 / 手机养鱼 / 先看门槛 / 非官方

### 00:45–01:30 它到底是什么

画面：
- 快速展示：群聊接梗、表情、图片、主动说话、日报/缓存；
- 文字卡：QQ 小号 + AI 群友 + 长期记忆 + 手机 24 小时在线。

口播：
“简单说，就是把一个 QQ 小号、SnowLuma、OneBot 和 DeepSeek 塞进一台安卓手机里的 Linux 虚拟机，让它像群友一样聊天、记忆、睡觉、偶尔主动冒泡。”
“它不是官方项目，不是免费服务，也不是装个 App 就能用。”

### 01:30–02:30 架构，30 秒看懂

画面：四层架构图：
Android → DroidVM 真 VM → Ubuntu → SnowLuma(chroot) → OneBot WS → bridge → DeepSeek。

口播：
“为什么不用 PRoot/udocker？因为 QQ 客户端、Xvfb、SnowLuma 需要真内核；PRoot 里 Docker 起不来，套娃也不稳。所以最后用了 DroidVM 真虚拟机。”
“SnowLuma 负责 QQ 和 OneBot，bridge 负责判断该不该回、怎么回、记忆和成本。”

### 02:30–04:30 门槛：先劝退

画面：逐张出现 5 张门槛卡，每张停留 3–5 秒。

1. 设备
   - Android 13+
   - 已 root
   - Gunyah / GenieZone / KVM
   - 8 GB RAM 起，12 GB 更稳
   - 20 GB 空间
   - 长期供电/网络

2. 账号
   - 全新 QQ 小号
   - 不用主号
   - 接受非官方协议工具的封号风险

3. 软件与授权
   - DroidVM 官方 APK（闭源，仓库不打包）
   - SnowLuma 官方获取（EULA 非商业/再分发限制）
   - 本仓库不附带 SnowLuma rootfs/镜像/自动部署脚本
   - 需要自己按官方文档安装

4. 成本
   - DeepSeek API key + 余额
   - token 不是免费
   - 长期运行有 API 费用
   - 缓存/非思考模式能省，但省不到 0

5. 能力与时间
   - 基础 Linux/SSH
   - 能看日志、排错、重启服务
   - 首次部署至少 1–2 小时，遇到兼容问题可能更久
   - 没有“一键成功”保证

口播：
“如果你没有 root、手机不支持虚拟化、或者只想点两下就能用，那这条路线不适合你。”
“SnowLuma 还有自己的 EULA；这个仓库不代分发、不提供一键部署。你需要在 GitHub 看文档、自己完成官方安装。”
“另外，DeepSeek 不是免费的；长期跑要算 API 成本。”

### 04:30–05:30 适合谁 / 不适合谁

画面：左右分栏。

适合：
- 有 root 安卓旗舰/平板
- 愿意折腾 Linux/SSH
- 想要一个长期在线的 QQ AI 小号
- 能接受非官方工具风险

不适合：
- 用主号
- 没有 root/虚拟化
- 想要一键脚本
- 不能接受 API 费用/封号风险
- 没有时间排错

口播：
“看到这里觉得麻烦是正常的。门槛就是门槛，不是靠一个视频就能抹掉。”
“如果你属于右边，先收藏，别急着折腾。”

### 05:30–06:40 GitHub 上有什么

画面：
- GitHub 仓库首页、README、docs 目录滚动；
- 5 个卡片：完整教程 / 排错 / DSH-Agent 手册 / DockerTarBuilder / 视频脚本。

口播：
“完整教程我已经放在 GitHub：从 DroidVM、Ubuntu、SnowLuma、OneBot 到 bridge 配置，还有排错、备份、DSH/Agent 抄作业手册。”
“SnowLuma 镜像怎么用 GitHub Actions 拉、怎么在手机-only 情况下拿 tar，也写了。仓库不包含 SnowLuma 二进制、DroidVM APK 和个人数据。”

画面字：
- 完整步骤在 docs
- 不在视频里逐条敲
- 仓库不放 rootfs/APK/个人数据

### 06:40–07:30 五步总览（不展开）

画面：5 个图标/步骤卡，每张 2 秒：
1. 准备 root 手机/VM
2. 官方安装 SnowLuma
3. 接 OneBot
4. 装 bridge/配置
5. 测试/备份

口播：
“流程大概五步：手机和 VM、SnowLuma、OneBot、bridge、测试备份。”
“每一步的详细命令、常见报错、验收标准都在 GitHub，不在这里展开。”

### 07:30–08:00 结尾：先看门槛，再决定

画面：
- 手机 + 架构图 + GitHub 链接；
- 风险声明字幕。

口播：
“这不是一个适合所有人的项目。它更像一个‘把手机变成长期在线的 AI 小号主机’的实验。”
“先去 GitHub 看 README 和门槛；不适合就省下时间，适合再动手。只用小号，别用主号。”
“仓库链接在简介和置顶评论，拜拜。”
