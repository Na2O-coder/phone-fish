# 分镜/录屏清单

## 拍摄前准备

- 独立演示 QQ 小号 + 演示群（不要用线上 bot）；
- 手机清桌面、关通知、隐藏私人 App/相册；
- 电脑不需要；用手机自带录屏 + DroidVM 录屏/截图；
- 录音：手机麦克风或外接麦，环境安静；
- 剪辑：手机剪映即可；16:9 1080p；
- 马赛克模板：QQ 号/群号/头像/二维码/key/token/IP/路径/通知。

## 录制注意

- 手机录屏时关闭自动亮度/旋转/通知；
- VM 画面用 DroidVM 的 VNC/控制台，分辨率固定 16:9；
- 终端字体调到 18–20，命令一行别太长；
- 每个步骤先录成功，再录一次失败/修复；
- 不要录到剪贴板、浏览器密码管理器、API 控制台 key。
