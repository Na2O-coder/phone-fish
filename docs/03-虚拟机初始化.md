# 03 · 虚拟机初始化

以下命令都在 Ubuntu VM 内执行。

## 1. 基础依赖

~~~bash
sudo apt-get update
sudo apt-get install -y python3 python3-venv sqlite3 curl unzip ca-certificates openssh-server
sudo systemctl enable --now ssh
~~~

也可以直接用仓库脚本：

~~~bash
sudo sh vm/setup-vm.sh
~~~

脚本只做通用初始化，不安装、不分发 SnowLuma。

## 2. 禁止自动休眠

~~~bash
sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
~~~

手机端也要在系统设置里允许 DroidVM 后台运行、关闭电池优化；否则 VM 会被杀。

## 3. 时区

~~~bash
sudo timedatectl set-timezone Asia/Shanghai
date
~~~

bridge 的睡眠/日报/主动消息按这个时区工作。

## 4. 目录

~~~bash
sudo mkdir -p /opt/snowluma/bridge /opt/snowluma/data /opt/snowluma/config /opt/snowluma/local-share
sudo chown -R "$USER:$USER" /opt/snowluma
~~~

SnowLuma 的 rootfs 路径由你自己的安装方式决定；bridge 只假设：

- bridge 代码在 /opt/snowluma/bridge；
- 状态/DB 在同目录；
- SnowLuma OneBot 在 127.0.0.1:3001。

## 5. 检查 SSH

在手机端：

~~~bash
ssh -p 2222 <你的用户名>@127.0.0.1
~~~

能看到 VM shell 就说明端口转发成功。

## 6. 共享目录/文件传输

优先用 DroidVM 的共享目录；没有就：

~~~bash
scp -P 2222 phone-fish-v0.1.0.zip <用户>@127.0.0.1:/tmp/
~~~

## 7. 资源检查

~~~bash
free -h
df -h /
nproc
python3 --version
~~~

至少要留 5 GB 空闲磁盘给 rootfs/日志/备份。
